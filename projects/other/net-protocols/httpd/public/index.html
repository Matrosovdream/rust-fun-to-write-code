It works.

This page came from httpd, a static file server written from raw TCP sockets: a hand-written HTTP/1.1 parser, a thread pool, and about as many lines of Rust as fit in an evening.

Things to poke at

  • /files/: a directory with no index.html, so you get a listing
  • /files: no trailing slash, so you get a 301 first
  • /files/hello.txt: plain text
  • /nope: a 404

From a terminal

curl -v 127.0.0.1:8180/
curl -I 127.0.0.1:8180/style.css
curl -v --path-as-is 127.0.0.1:8180/../Cargo.toml   # 403
curl -v 127.0.0.1:8180/ 127.0.0.1:8180/style.css    # one connection
